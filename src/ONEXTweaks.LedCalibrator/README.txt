ONEXTweaks LED Calibrator 0.3

Диагностическое мини-приложение Windows для ручного сравнения 24 экранных
RGB-образцов с подсветкой ONEXPLAYER 3 на каждом из четырёх уровней яркости.
Всего 4 отдельных этапа: 4/4, 3/4, 2/4, 1/4 (96 пар цвет/яркость).
Оно собирает наблюдения владельца,
а не измеряет свет и не устанавливает готовую коррекцию всей палитры.

Три независимые группы:
  Верхняя — верхняя зона (OEM 6).
  Стики — оба стика вместе (OEM 1 и 2).
  Нижняя — подсветка кнопки меню (OEM 5).
Разъём контроллера OEM 7 не калибруется; его исходное состояние сохраняется.

Порядок работы:
1. Нажать «Начать» или «Продолжить». До этого подсветка не меняется.
2. Сравнить большой цветной образец с каждой физической группой.
3. Выбрать группу. Можно двигать шесть ползунков или нажимать кнопки ±.
   Тон — сам оттенок, в градусах. Насыщенность: 0% — нейтральный цвет,
   100% — насыщенный оттенок. Яркость цвета RGB: ниже — темнее, выше —
   светлее; мощность LED остаётся на уровне выбранного этапа. R/G/B —
   отдельные каналы 0–255. Это диагностические регулировки.
   Для кнопок, стрелок и числовых полей доступны шаги 1, 2, 5, 10 и 20.
   Для тона это градусы, для насыщенности/RGB-интенсивности — процентные
   пункты, для отдельных каналов — единицы 0–255. Тач/мышь дают шаг 1.
4. Оценить отдельно верх, стики и кнопку. «Приемлемо» и «Нужна доработка»
   сохраняются отдельно от «Подходит», их не следует считать точной калибровкой.
5. Нажать «Дальше». После 24-го цвета автоматически начинается следующий
   этап яркости. Можно вернуться назад или выбрать этап справа. Все изменения сохраняются
   автоматически после подтверждения команды помощником.
6. «Закрыть» возвращает подсветку, действовавшую до начала прогона.

Результаты одного образца на разных уровнях яркости сохраняются отдельно,
включая оценки и комментарий. Новый уровень начинается с ближайшего
сохранённого RGB, но оценки нужно поставить заново. «Сброс выбранных»
возвращает стартовый цвет только у выбранной группы или у всех трёх,
если явно выбраны «Все 3 зоны». Оценки соседних групп и другие этапы сохраняются.
Последний прогон можно продолжить при следующем запуске. Данные 0.1
переносятся в 0.2, включая ранее завершённые 24 цвета: уровни 3/2/1 ещё
требуют отдельных оценок.

Перетаскивание сразу меняет положение ползунка и цифры. Аппаратные команды
объединяются: пока выполняется одна, сохраняется только последнее новое
положение. Промежуточные положения не образуют длинную очередь. После
применения используется подтверждение из ответа Set, без повторного Get.

Файлы:
  %LOCALAPPDATA%\ONEXTweaks\dev\Reports\LedCalibration\visual-*.json
  %LOCALAPPDATA%\ONEXTweaks\dev\Reports\led-calibration-latest.json
В JSON сохраняются экранный sRGB, желаемые и подтверждённые OEM RGB-байты,
физическая группа, уровень яркости, оценка и комментарий. Подтверждение OEM
не является оптическим измерением. Пометки qa-* относятся только к автотестам.

Независимая задача Windows возвращает исходную подсветку после 15 минут
бездействия; она сработает и при сбое приложения. Обратный отсчёт виден в окне. Если настройки
подсветки изменены другим приложением, более новое состояние не затирается.

Сборка: tools\Build-LedCalibrator.ps1 из каталога ONEXTweaks.
Для работы требуются установленный ONEXTweaks Bridge/PowerAgent с цветовым
преобразованием srgb-to-linear, существующий набор tools\led-palette-survey-cases.json
и tools\compare-led-primary.ps1 в локальном dev-каталоге. Сама сборка это
окружение не устанавливает. Текущий бинарник установлен средствами разработки.

Повторное использование: CalibrationCore.cs содержит только DTO, карту групп
и цветовую математику. Их можно использовать в виджете; WinForms-интерфейс
и транспорт CalibrationSession потребуют подключения к интерфейсу виджета.
Исходные эмпирические поправки — стартовые образцы, а не доказанная модель
всей палитры. После сбора нужны построение модели и отдельные контрольные цвета.

0.3: диагностические RGB обходят установленную коррекцию помощника,
чтобы результат повторной калибровки не корректировался дважды.
Завершённые результаты 0.2 сохраняются в исходном архиве.

Localization 0.4: follows the widget language selected in Appearance; English when no app language is selected. Existing result IDs, comments and calibration session format are unchanged. Localization QA uses an isolated preview form and never starts an LED session.
